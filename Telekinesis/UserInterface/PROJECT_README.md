# Telekinesis — frontend

The whole game lives here: camera → hand tracking → gestures → swarm physics → canvas. The backend (`../`) only hosts the window and a tiny local API.

## Stack
Vue 3 (`<script setup lang="ts">`) · TypeScript · Vite · Pinia (setup stores) · vue-router (**hash history**, the desktop host serves a static `index.html`) · Tailwind CSS v4 (`@tailwindcss/vite`, tokens in `src/assets/main.css`) · MediaPipe Tasks Vision (`@mediapipe/tasks-vision`, Hand Landmarker) · Vitest · Playwright. Node `^22.18` or `>=24.12`.

```
    swarm.ts               the simulation (`Swarm`, `TUNING`, `SwarmInput`)

```
Build output goes to `../wwwroot` (served by the desktop host in Release).

## How it works
1. **`useHandInput`** reads frames from the webcam (unmirrored) and runs the Hand Landmarker (≤ 2 hands).
2. **`GestureTracker`** (`helpers/gestures.ts`) turns the 21 landmarks per hand into `HandSignals`. Everything is distance based, so it works with any hand or camera rotation. MediaPipe's `Left`/`Right` label is used as is (for unmirrored frames it is already the user's own hand).
3. **`game/input.ts`** maps the primary hand (right preferred) to a `SwarmInput` = `{ pose, dir, pinch, drift, reach, stop }`. The hand **chooses the behaviour; it never places the balls** (no position in `SwarmInput`). `StopDetector` watches both hands.
4. **`Swarm.step(dt, input)`** advances the simulation. Every gesture is *one force on velocity*; momentum, air drag, walls and gravity do the rest.
5. **`GameView`** draws it: white stage, black outlines only, no fills.

Without a camera the mouse stands in for the hand (see the table below).

## Gestures
| Hand | Effect |
|---|---|
| **Open palm** (a fist with the *back* toward the camera counts as open) | Gravity off. Balls keep their velocity; only the air drag slows them. From the floor each ball gets a small random upward kick. **Waving** the open hand drifts a random, changing subset of balls slowly the way the hand moves; the closer the hand, the more balls and the faster. |
| **Fist** (palm toward the camera) | Gravity back on — the swarm drops with the speed it had. |
| **Point** (index only) | Move: an invisible line grows from the swarm along the finger; the ball at the head is caught first, then it works back, so the swarm stretches into a comet. The push grows the longer you hold it. **Hand distance sets the speed** (a close hand pushes harder and reaches a higher top speed). |
| **Two fingers** (index + middle) | Circle around the centre point. |
| **Pinch** (thumb + index) | Pull the balls together toward the centre point (works in every floating mode; releasing leaves the clump where it is). |
| **Both hands open**, held ~0.3 s | Stop: brake to a standstill, then keep floating there. |

*Centre point* (circle / pinch) = the swarm's middle, or **the front ball if the swarm is moving**; it keeps coasting with that ball's own velocity.

**Mouse fallback** (the mouse button in the game's top bar): hold the button = open palm · move the mouse = wave · **Shift** = two fingers · **arrow keys / WASD** = point · **Alt** = pinch · **Space** = both hands open · **wheel** = hand distance · release = fist.

## Conventions
- **Hand never steers.** `SwarmInput` has no position; a new gesture = a new pose or value in `SwarmInput` + one force in `Swarm.step`, with a physics test.
- **No hidden "comfort" forces** (no spacing / gathering unless a gesture asks for it). A gesture's forces act on a ball only once that gesture has reached it (its engagement `e`); everything else just coasts.
- **The simulation has its own units** (ball radius 10, cloud 175, gravity 4500, … in `TUNING`), independent of the window. `VIEW_ZOOM` only decides how much of the world is visible (0.16 → balls ≈ 1.6 px radius, window ≈ 6800 × 4400 world units). Pushes are tied to a fixed `pushRefDrag`, so changing `airDrag` only changes how long things coast.
- **All tuning numbers live in `TUNING`** (`game/swarm.ts`) and `THRESHOLDS` (`helpers/gestures.ts`), each with a comment. Change a number there, not in the logic.
- API calls only through `services/*Api.ts` → `httpClient.requestJson`. `diagnosticsApi.reportDiagnostic` prints UI status lines to the host console (the WebView console isn't readable from a terminal).
- **Every clickable has an icon** (`AppIcon`); icon-only controls carry `title` + `aria-label`; interactive elements have a `data-testid`. Enforced by `e2e/icons.spec.ts`.
- UI template: `UI templates/minimal-ui-components.html` (light tokens in `src/assets/main.css`). **Deliberate deviation for the stage:** pure white background, black outlines.

## Testing
- Unit (Vitest): `npx vitest run` — `helpers/__tests__/gestures.spec.ts` (synthetic 21-point hands, rotation, facing), `game/__tests__/swarm.spec.ts` (physics invariants: floats, coasts, stops, comet shape, order of engagement, caps…), `game/__tests__/input.spec.ts`. (`npm run test:unit` starts watch mode.)
- E2E (Playwright, Chromium with a **fake webcam**, `npx playwright install chromium` once): `npx playwright test` with `npm run dev` running. The game is driven through the mouse fallback; ink is measured from the canvas pixels (the floor line is detected as "a row that is mostly ink", so it works at any zoom).
- Lint / types: `npm run lint`, `npx vue-tsc --build`.

## Feature log
Current state of each feature (not a history — update the bullet when a feature changes).
- **Home** (`/`): title, backend version pill (`GET /api/app/version`), links to Play and Camera spike. *Fully wired.*
- **Camera spike** (`/spike`): webcam → hand skeleton + per-hand readout; the debugging tool for tracking and gestures. Logs pose / facing changes to the host console. *Fully wired.*
- **Hand tracking & gestures** (`helpers/`, `composables/`): bundled offline model (GPU, CPU fallback); smoothed signals; poses `open / fist / point / two / pinch`; **facing** (palm vs back of the hand from the knuckle winding + fingertip depth — a back-facing fist = open); pointing direction; hand speed (drift) and size (distance). Verified on a real webcam in the macOS window.
- **Swarm physics** (`game/swarm.ts`): 60 balls, gravity, drag, bouncing walls / floor, a position correction only against interpenetration; start as a heap in the middle of the floor. All unit-tested.
- **Levitate / drop**: open palm = gravity off (+ kick from the floor); fist = drop.
- **Wave drift**: open hand moving → slow drift of random balls; `reach` (hand size) scales how many and how fast.
- **Move** (point): head-first stream, comet shape, push that grows while held, hand distance sets speed and the top speed cap (only for stream-carried balls).
- **Circle / pinch**: swirl or clump around the centre point (front ball while moving).
- **Stop** (both hands open): braking drag, lets go of the stream, switches the drift off.
- **Mouse fallback**: every gesture above can be driven from the mouse and keyboard.
- Not yet verified / not done: Windows (WebView2); a packaged macOS app (needs `NSCameraUsageDescription`); a Release build serving the `.wasm` / `.task` files; on a 1× display the balls are small dots (looks right at 2×).
